FloCafe يعمل مباشرة على جهاز المتجر. يتم تخزين الطلبات والعملاء والإيصالات والنسخ الاحتياطية في قاعدة بيانات SQLite محلية، ما يتيح استمرار خدمة الطاولة وشاشات المطبخ في العمل دون اتصال بالإنترنت. لا يلزم وجود حساب سحابي أو مستضاف لاستخدام النظام الأساسي الأساسي. كما يمكن تفعيل التكاملات الاختيارية مثل نسخ Google Drive الاحتياطي، وإرسال الفواتير عبر WhatsApp، والتقارير المرتبطة بالسحابة عند الحاجة.

## الحصول على FloCafe

حمّل أحدث مثبت من [إصدارات GitHub](https://github.com/FreeOpenSourcePOS/FloCafe/releases)، أو قم بالتثبيت عبر متجر التطبيقات الخاص بنظام التشغيل:

- متجر تطبيقات macOS
- متجر Microsoft
- متجر Snap

تتضمن الإصدارات مثبتات Windows، وملفات DMG لنظام macOS، وباقات AppImage و`.deb` و`.rpm` وSnap لنظام Linux. لمزيد من التفاصيل حول تثبيت Linux وتحديثاته وتصاريح الطباعة وسلوك شريط النظام، راجع [دليل التثبيت والدعم لنظام Linux](docs/linux.md).

### متطلبات النظام

| المتطلب | الحد الأدنى |
| --- | --- |
| نظام التشغيل | Windows 10+ أو macOS 12+ أو أي توزيع Linux مدعوم |
| الذاكرة | 4 جيجابايت RAM |
| التخزين | 500 ميجابايت مساحة حرة بالإضافة إلى مساحة للنسخ الاحتياطية المحلية |

Node.js مطلوب فقط لتطوير FloCafe وليس لتشغيل النسخة المجمعة.

## أبرز الميزات

- **تدفق الطلبات:** طلبات المطعم، تناول الطعام داخل المحل، الاستلام من الخارج، والتوصيل مع إدارة الطاولات والطلبات المؤجلة.
- **التعديلات والتسعير:** تعديلات العناصر، مجموعات الإضافات، الخصومات، ونقاط الولاء.
- **طباعة الإيصالات:** طباعة ESC/POS الحرارية عبر USB، الشبكة المحلية (TCP)، وقوائم الطباعة المدارة من النظام، مع دعم WebUSB في المتصفحات المتوافقة ودعم ورق 58 مم و80 مم.
- **عمليات المطبخ:** خادم شاشة المطبخ المستقل (KDS) وتوجيه المحطات حسب الفئة.
- **إدارة الكتالوج:** صور المنتجات، ومسح الباركود، واستيراد/تصدير قائمة الطعام بصيغة CSV.
- **الإدارة:** حسابات الموظفين بالأدوار (المالك، المدير، الكاشير، الخادم، الطاهي)، وتحليلات المبيعات، وسجلات التدقيق.
- **حماية البيانات:** قاعدة بيانات SQLite محلية، نسخ احتياطية تلقائية قبل الترحيل، وأدوات استعادة يدويّة، مع نسخة احتياطية اختيارية على Google Drive.

## حالة المشروع

يُطور FloCafe بانتظام ويستخدم بالفعل في بيئات تشغيل حقيقية. تُعامل بيانات العملاء وسلامة ترقيات النظام باهتمام، مع ترحيلات قاعدة بيانات واضحة وآليات استرداد. لا يزال جزء من البنية الداخلية والواجهات الخارجية قيد التطور، لذلك قد تتغير تفاصيل التنفيذ والعقود الداخلية مع نضج المشروع.

## تصميم يعمل دون اتصال

تشغيل نقطة البيع الأساسية والبيانات المحلية يعمل دون اتصال. لا تعتمد إدخال الطلبات والفوترة وتنسيق شاشة المطبخ وطباعة الإيصالات على الإنترنت أو على خدمات سحابية خارجية.

- **موقع البيانات:** توجد قاعدة بيانات SQLite والنسخ الاحتياطية المحلية في دليل بيانات المستخدم، بعيدًا عن ملفات التطبيق المثبتة. لا تقم التحديثات العادية بحذف هذه البيانات. يوصى بإنشاء نسخة احتياطية يدويّة قبل إعادة التثبيت أو النقل إلى جهاز جديد أو تغيير قناة التوزيع.
- **النسخ الاحتياطية قبل الترحيل:** ينشئ FloCafe نسخة احتياطية مؤرخة تلقائيًا قبل تشغيل ترحيل المخطط.
- **الميزات الشبكية الاختيارية:** خوادم مثل نسخ Google Drive الاحتياطية، وإرسال الفواتير عبر WhatsApp، والتقارير السحابية تتواصل عبر الشبكة فقط عند التفعيل والتكوين الصريحين من قبل مالك المتجر.

## اللغات والدعم الإقليمي

يدعم FloCafe واجهة مستخدم باللغة العربية والإنجليزية والإسبانية والفرنسية والبرتغالية البرازيلية والفلبينية والتركية والفارسية (Farsi)، مع دعم RTL للعربية والفارسية، والألمانية والإيطالية واليابانية والصينية المبسطة والكورية وBahasa Indonesia.

لغة الواجهة مستقلة عن بلد المتجر والإعدادات الإقليمية، بينما تبقى قواعد حساب الضرائب مجالًا منفصلًا. لمزيد من التفاصيل حول المساهمة في الترجمات أو إضافة لغات جديدة، راجع [دليل التدويل والترجمة](docs/i18n.md).

## التطوير

يتطلب تطوير FloCafe Node.js 22 أو إصدار أحدث:

```sh
git clone https://github.com/FreeOpenSourcePOS/FloCafe.git
cd FloCafe
npm install
npm run dev
```

يقوم الأمر `npm run dev` بترجمة الواجهة الأمامية والخلفية ثم تشغيل Electron.
