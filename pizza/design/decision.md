# Layout decision

Chosen by the owner on 2026-11-25: every recommended variant.

| Screen | Variant |
| :--- | :--- |
| 1. POS home | A: size buttons on every pizza tile, cart actions always showing |
| 2. Pizza sheet | A: both halves side by side, everything on one screen |
| 3. Deal configurator | A: tabs, each tab the pizza sheet, a "still missing" box |
| 4. Quick buttons | A: a full page of buttons, plus B's row of a customer's favourites after a phone lookup |
| 5. Small-items popup | B: the order stays visible, each tap is an ordinary add |
| 6. Kitchen ticket | The one version drawn, `1ST:` and `2ND:` for halves |

From the notes, to carry into the build: fold cart action rows away on all but the last-touched line once an order passes three or four lines; switch Add off with a message while both halves are identical; offer "Customize 1" on pizza lines.
