FloCafe براہ راست آپ کے کاروبار کے کمپیوٹر پر چلتا ہے۔ آرڈرز، گاہک، رسیدیں اور بیک اپ مقامی SQLite ڈیٹابیس میں محفوظ رہتے ہیں، اس لیے کاؤنٹر سروس اور کچن ڈسپلے بغیر انٹرنیٹ بھی کام کرتے ہیں۔ بنیادی POS کے لیے کسی کلاؤڈ اکاؤنٹ یا ہوسٹنگ کی ضرورت نہیں۔ Google Drive بیک اپ، WhatsApp بل ترسیل اور کلاؤڈ رپورٹنگ جیسے اختیاری سروسز ضرورت پڑنے پر فعال کی جا سکتی ہیں۔

## FloCafe حاصل کریں

[GitHub Releases](https://github.com/FreeOpenSourcePOS/FloCafe/releases) سے تازہ ترین انstaller ڈاؤن لوڈ کریں یا اپنے پلیٹ فارم کی ایپ اسٹور سے انسٹال کریں:

- macOS App Store
- Microsoft Store
- Snap Store

ریلیزوں میں Windows انسٹالرز، macOS DMG اور Linux کے AppImage، `.deb`، `.rpm` اور Snap پیکجز شامل ہیں۔ Linux کے پیکیج، اپ ڈیٹ، پرنٹنگ کی اجازت اور ٹرے کے بارے میں مزید معلومات [Linux تنصیب اور معاونت](docs/linux.md) میں ہیں۔

###سسٹم تقاضیاں

| تقاضہ | کم از کم |
| --- | --- |
| آپریٹنگ سسٹم | Windows 10+، macOS 12+ یا معاونت یافتہ موجودہ Linux ورژن |
| میموری | 4 GB RAM |
| اسٹوریج | 500 MB خالی جگہ، علاوہ ازیں مقامی بیک اپس کی جگہ |

Node.js صرف FloCafe کی ترقی کے لیے درکار ہے، تیار پیکج ایپ چلانے کے لیے نہیں۔

## اہم خصوصیات

- **آرڈر ورک فلو:** کاؤنٹر، ٹیبل سروس، ٹیک اوے اور ڈیلیوری آرڈرز کے ساتھ میز کا انتظام اور روکے گئے آرڈرز۔
- **ترمیمات اور قیمتیں:** آئٹم ترمیمات، ایڈ آن گروپس، رعایتیں اور وفاداری پوائنٹس۔
- **رسید پرنٹنگ:** 58 mm اور 80 mm کاغذ پر USB، مقامی نیٹ ورک، OS پرنٹ قطار اور WebUSB کے ذریعے ESC/POS تھرمل پرنٹنگ۔
- **کچن آپریشنز:** خودمختار Kitchen Display System (KDS) اور زمرے کے مطابق کچن اسٹیشن راؤٹنگ۔
- **کیٹلاگ انتظام:** پروڈکٹ تصاویر، بارکوڈ اسکیننگ اور CSV مینو درآمد/برآمد۔
- **انتظام:** کردار کے مطابق ملازم اکاؤنٹس، فروخت تجزیہ اور آڈٹ لاگز۔
- **ڈیٹا تحفظ:** مقامی SQLite ڈیٹابیس، خودکار پری مائیگریشن بیک اپ، دستی بحالی اور اختیاری Google Drive بیک اپ۔

## پروجیکٹ کی حالت

FloCafe مسلسل ترقی کر رہا ہے اور حقیقی کاروباری ماحول میں استعمال ہو رہا ہے۔ گاہکوں کے ڈیٹا اور اپ ڈیٹ کی حفاظت پر خاص توجہ دی جاتی ہے، جس میں واضح ڈیٹابیس منتقلیاں اور بحالی کے طریقے شامل ہیں۔ کچھ اندرونی اور توسیعی معماری ابھی بھی تیار ہو رہی ہے، اس لیے تفصیلات بدل سکتی ہیں۔

## بنیاد طور پر بغیر انٹرنیٹ

بنیادی POS، مقامی ڈیٹا، KDS اور رسید پرنٹنگ انٹرنیٹ یا بیرونی کلاؤڈ سروسز پر انحصار نہیں کرتے۔

- **ڈیٹا کا مقام:** SQLite ڈیٹابیس اور بیک اپس OS کے صارف ڈیٹا فولڈر میں رہتے ہیں، انسٹال فائلوں سے الگ۔ عام اپ ڈیٹ انہیں حذف نہیں کرتے۔ دوبارہ انسٹال، منتقلی یا ڈسٹریبیوشن تبدیل کرنے سے پہلے دستی بیک اپ لینا بہتر ہے۔
- **منتقلی سے پہلے بیک اپ:** FloCafe اسکیما منتقلی سے پہلے خودکار طور پر timestamp شدہ ڈیٹابیس بیک اپ بناتا ہے۔
- **اختیاری نیٹ ورک سروسز:** Google Drive بیک اپس، WhatsApp بل ترسیل اور کلاؤڈ رپورٹنگ صرف دکان کے مالک کی واضح ترتیب اور فعال کرنے پر بیرونی نیٹ ورک استعمال کرتی ہیں۔

## زبانیں اور علاقہی معاونت

FloCafe انگریزی، اسپینش، فرانسیسی، برازیلی پرتگالی، فلپائنو، ترکی، فارسی، عربی، اردو، جرمن، اطالوی، جاپانی، 简体 چینی، ٹائیوان کا روایتی چینی، کوریا، Bahasa Indonesia، ڈچ، ہندی، بنگالی، البانی اور ویتنامی میں UI ترجمے فراہم کرتا ہے۔

اردو عربی رسم الخط اور RTL ترتیب استعمال کرتا ہے۔ فون نمبر، URL، آرڈر نمبر، رقم اور دیگر قدرتی LTR ڈیٹا الگ LTR جزو کے طور پر دکھائے جاتے ہیں۔

UI زبان اسٹور کے ملک، کرنسی، ٹائم زون اور ٹیکس قوانین سے الگ ہے۔ یہ علاقہی ترتیباتیں آپ کے منتخب کردہ ملک اور کرنسی کے مطابق طے ہوتی ہیں۔ تفصیلات [بین الاقوامیکریشن اور ترجمہ رہنمائ](docs/i18n.md) میں ہیں۔

FloCafe 131 ملکی پروفائلز اور 109 کرنسیوں کے ساتھ آتا ہے۔ ملک، کرنسی اور ٹائم زون کی تفصیلات [پرنٹنگ رہنمائ](docs/printers.md) اور ملکی پروفائلز کے سیکشن میں موجود ہیں۔

## اردو میں رسید اور پرنٹنگ

اردو رسیدیں اور KOT ٹکٹس چھانٹے کے لیے اسٹور کی زبان یا چنی گئی پرنٹ زبان سے بنتے ہیں۔ جن جن پرنٹرز میں اردو حروف کی شکل بندی اور دوطرفہ ترتیب کی تصدیق نہیں ہو، FloCafe متن کو خاموشی سے ضائع نہیں کرتا؛ اس کے بجائے واضح انتباہ، براؤزر پرنٹ یا قابل تصدیق raster مسیر استعمال کیا جاتا ہے۔

## ترقی

FloCafe کی ترقی کے لیے Node.js 22 یا اس سے نیا ورژن درکار ہے:

```sh
git clone https://github.com/FreeOpenSourcePOS/FloCafe.git
cd FloCafe
npm install
npm run dev
```

`npm run dev` فرنٹ اینڈ اور بیک اینڈ بلڈ کر کے Electron شروع کرتا ہے۔
